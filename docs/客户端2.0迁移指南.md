# 客户端 2.0 迁移指南

JavaScript、Go、Android、iOS 2.0 将正式请求入口统一为 `request(SecureRequest)`。
线协议和服务端接口仍为 protocol v1，不需要修改服务端。

## 通用迁移

1. 将依赖升级到 2.0；Go import path 同时切换为 `/v2`。
2. 用 SecureClientConfig 配置 base URL、app ID、device type、trust anchors 和身份存储。
3. 将散参数请求构造成 SecureRequest，明确 logicalPath、contentType 和 protected headers。
4. 为 v2 配置新的身份位置。SDK 不读取、不覆盖且不删除 1.x 身份。
5. 非 H5 设备取得与 device type 匹配的新 enrollment token，首次启动调用 enroll。
6. 使用统一 SecureError 字段处理错误；业务重试必须创建新调用，SDK不会自动重发。

## 接口替换

JavaScript：

```js
// 1.x: client.request('POST', '/events', headers, body, requestId)
// 2.0:
await client.request(new SecureRequest({
  method: 'POST', logicalPath: '/events', contentType: 'application/json',
  protectedHeaders: headers, body
}), { signal });
```

Go：

```go
// 1.x: client.Request(ctx, "POST", "/events", headers, body, "")
// 2.0:
client.Request(ctx, securecommunication.Request{
    Method: "POST", LogicalPath: "/events", ContentType: "application/json",
    ProtectedHeaders: headers, Body: body,
})
```

Android：

```java
SecureClientConfig config = SecureClientConfig.builder() /* ... */ .build();
SecureResponse response = client.request(new SecureRequest(
        "POST", "/events", "application/json", headers, body, null));
```

iOS：

```swift
let response = try await client.request(try SecureRequest(
    method: "POST", logicalPath: "/events", contentType: "application/json",
    protectedHeaders: headers, body: body))
```

`SC_UNKNOWN_SESSION` 表示当前请求失败且会话已清除。下一次调用会重新握手；是否重发
原业务由调用方依据 message ID、batch ID 或其他幂等语义决定。
